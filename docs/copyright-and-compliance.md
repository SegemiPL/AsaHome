# 版权与合规

> **Human Review Required** — 本文件涉及的所有版权、合规和发布决策必须由维护者人工确认。

## 版权声明

### ASa Project 相关

- 官方指南允许一定范围的非商业介绍、引用和二次创作，但明确禁止素材分发
- 官方公开素材的使用必须保留来源、权利声明和禁止转载提示
- 解包得到的音频、文本、立绘不默认公开
- TTS 模型权重、数据集、完整脚本的公开范围必须人工确认
- "非商业化"不等于自动获得训练、公开模型或分发素材的许可

### 官方参考

- [ASa Project ガイドライン](https://www.asa-pro.com/top/guide/guide.html)
- [ASa Project サポート](https://www.asa-pro.com/support.html)

## 中国大陆合规

### ICP 备案

使用中国大陆服务器公开网站前必须完成 ICP 备案。

### AI 生成内容标识

- 生成合成音频功能上线前必须核对生成内容显式/隐式标识要求
- 参考：[生成合成内容标识办法](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)
- 标识要求是发布阻断项，不得以"项目非商业化"为由跳过

### 其他要求

若服务性质触及算法备案、安全评估或其他监管要求，必须由维护者咨询主管部门或专业人士。
