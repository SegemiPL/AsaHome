## 关于 AsaHome

AsaHome 是一个非官方、非商业化的个人技术展示项目。

本站主要包含：

- ASa Project 相关逆向工程的技术记录
- TTS 角色语音合成的研究与实验
- 桌面桌宠（WindowPet）的开发过程
- 角色资料的整理与展示

## 技术栈

本站基于 Next.js Static Export 构建，部署在静态托管平台上。所有内容通过 Markdown 和 TypeScript 静态数据管理。
